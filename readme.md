# Hello!
Магазин для продажи живых новогодних деревьев "Ёлкин двор".
Особенность - на сайте не будет платежной системы, 
посетитель заказывает доставку, он и менеджер магазина получают письмо с 
номером заказа и информацией по заказу, оплата при доставке наличными.

- на сайте будет промокод


- Вместо runserver во время верстки мы будем использовать эту команду. 
- Она параллельно запускает Django-сервер и компилятор Tailwind
- `python manage.py tailwind start`
- http://127.0.0.1:8000/
